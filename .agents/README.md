# Vendored agent skills

The skills in this directory are vendored, unmodified, from Supabase's
[`supabase/agent-skills`](https://github.com/supabase/agent-skills) repository:

- `skills/supabase/`
- `skills/supabase-postgres-best-practices/`

`skills-lock.json` at the repository root records the upstream source and a
content hash for each skill. Do not edit the skill files by hand - that would
make the recorded hash wrong. Update them from upstream instead.

Upstream is MIT licensed. `LICENSE` in this directory is Supabase's licence
text, copied verbatim, because MIT requires the copyright and permission notice
to travel with the files.
